# Sistema de escritorio para procesos con efectuación de denuncias
## Comisaría PNP Payet, Lima 2026

## Descripción
Sistema desarrollado en Python para la Mesa de Partes de la Comisaría PNP Payet.
Permite registrar trámites de ciudadanos, emitir el cargo de recepción digital y
administrar los expedientes. Usa control de versiones con Git y GitHub.

## Tecnologías
- Python 3
- Visual Studio Code
- Git y GitHub

## Funcionalidades
- Registrar trámite u ocurrencia (con validación de DNI)
- Buscar expediente por DNI
- Mostrar todos los expedientes
- Ordenar expedientes (método burbuja)
- Cancelar o eliminar expediente

## Ejecución
```
python main.py
```
